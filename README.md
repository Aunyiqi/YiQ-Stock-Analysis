# YiQ Stock Analysis – Interactive Stock Analysis and Price Prediction System

## Overview

YiQ Stock Analysis is a web-based stock market analysis system developed using HTML, CSS, and JavaScript. The application provides users with interactive stock price visualization, technical analysis, and basic price prediction features through a modern and responsive interface. It supports multiple chart types, drawing tools, technical indicators, and simulated forecasting models for educational and demonstration purposes.

## Application Workflow

1. Enter a stock symbol (e.g. AAPL).
2. Click **Analyze**.
3. The system validates the stock symbol.
4. Historical stock data is displayed.
5. Technical indicators are calculated.
6. Users can:
   - Switch chart type
   - Draw trend lines
   - Draw horizontal lines
   - Zoom and pan charts
7. Select a prediction method.
8. Choose the prediction period.
9. Generate a price prediction.
10. View the prediction result, confidence level, market trend, and recommendation.
